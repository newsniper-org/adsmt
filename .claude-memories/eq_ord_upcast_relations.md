**오너 확정 (2026-07-03): #391은 type relation으로 푼다.** 규범 스펙 (설계 문서 `docs/design/EQ_ORD_UPCAST_RELATIONS.md`가 원본):

- `PartialEq(A, B)` 2-param; **A≠B일 때 `PartialEq(A,B)` 인스턴스는 `PartialEq(B,A)`를 암시적으로 동기화**(레지스트리가 거울 생성, 명시적 거울 중복선언은 오류).
- `Eq(T)` : `PartialEq(T, T)` 상속.
- `UpCast(A, B)` = **상위 자료형으로의 실패없는 캐스팅** type relation (elaborator의 하드코딩 numeric lattice Nat⊂WNat⊂Int⊂Real의 일반화). **`UpCast(T,T)`는 빌트인(항등)이며 명시적 구현 금지**(admission 오류).
- `PartialOrd(T, A)` : **`PartialEq(T, A)`와 `UpCast(T, A)`를 동시에 상속** (교차-소트 비교는 상위 캐리어에서 결정).
- `Ord(T)` : **`PartialOrd(T, T)`와 `Eq(T)`를 동시에 상속.**

**함의**: (1) 기존 adsmt-class numberlike의 1-param `PartialOrd(I)`/`Ord(I)`를 이 2-param 계층으로 재편(상속=인스턴스 premise 관용구, `ord_instance` 선례); (2) lukb elaborator의 `=`/비교 sort-통일을 하드코딩 lattice(`numeric_rank`/`inject`) 대신 relation 해석으로 재라우팅(판정 무변 필수); (3) `data` 선언이 lawful `Eq(T)` 자동 도출(법칙은 datatype theory가 방증) → `is-C(x)`가 `x = C` / shape biconditional로 elaborate되어 #391 폐쇄(ob1-abs.lukb 관통). 스테이징 F1(adsmt-class 패밀리)→F2(elaborator 재라우팅)→F3(Eq 자동도출+tester)→F4(문서/통지). **충돌 재정 3건 (오너, 2026-07-03, 같은 날 후속)**: ① numberlike 1-param PartialOrd/Ord **전면 재편** — 기존 premise 사용처 전부 대각선 `PartialOrd(T,T)`로 이전(빌트인 항등 UpCast가 상속 premise 자명 충족), Ord(T)에 Eq(T) premise 추가, 내부 API 파괴 수용. ② **Rust식 Eq-게이팅**: `=`/`!=` 사용에 Eq(T) 인스턴스 필수; 기존 동작 보존 위해 모든 선언 소트(sort S, GF(p)/IntModulo/GFPower, Prop, 숫자, data)에 **빌트인 Eq 자동 부여** — 게이트는 명시화되되 당장은 관찰상 보수적, 향후 Eq-없는 소트 opt-out 가능. ③ **UpCast/Reduces 별개 공존**: UpCast=표면/elaboration 층의 실패없는 임베딩, Reduces=해결-시 이론 환원 spine; 숫자 UpCast 인스턴스의 캐스트 메서드는 기존 주입 상수(nat2int/to_real 등) 재사용, 새 커널 심볼 없음. **또한 표준 규칙**: 지시가 기존 구현과 충돌하면 즉각 질문할 것 (이번 세 재정이 그 선례).

**추가 재정 (오너 후속, 2026-07-03): `UpCast(A,B)`는 `Reduces(A,B)`를 상속.** 방향 근거: 실패없는 상위형 임베딩은 환원의 한 변(cast=encode, 이미지 특성화=refinement 술어 — ℕ↪ℤ positivity guard가 그 사례)이지만 역은 불성립(GF(p)→Int mod-p decode, Complex→(Real,Real) 표현변경은 Reduces이되 UpCast 아님) ⇒ UpCast ⊂ Reduces, 강자가 약자를 상속(Eq:PartialEq 꼴). 빌트인 UpCast(T,T) 항등은 빌트인 Reduces(T,T) 항등을 동기화. Reduces는 아직 구체 Relation이 아니므로(numberlike "Reduces-spine-deferred") 이 상속변은 Reduces 실체화 시점에 발효 — 그때까지 UpCast는 Reduces premise를 지니지 않음.
