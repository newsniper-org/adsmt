**Multi-paradigm hybridization of adsmt** — design exploration started 2026-06-24 (brainstorm). Goal: a reasoning workbench combining SMT + ASP + (later) CP + HO-ATP, with adsmt as the integrating substrate.

**Decided (user calls):**
- **Frontend modeling language** = a *separate* language (NOT Rust-hosted — Rust lacks HKT/embedded-blocks/I/O-ban), compiling to a *typed Rust IR* (the language-agnostic core lingua franca). Required features: embedded SMT-LIB blocks (Flix-Datalog / Scala-3-DSL style), HKT, statically typed + inference, **I/O syntactically impossible** (effects = CLI *requests*, à la Elm/free-monad — purity = §3.5 replay determinism as a language invariant). Pure Rust core + separate language *because the core must not be tied to any emitter output language* (= adsmt-emit's language-agnostic principle applied to BOTH ends: frontend modeling langs + backend proof/cert langs are pluggable adapters).
- **Language shape** = a **strict superset whose two 1:1 subsets are SMT-LIB v3 and typed-Datalog**. KEY: "subset, not whole" is deliberate — the *organic ASP⊕SMT cooperation lives in the strict-superset INTERIOR* (mixed sentences neither subset expresses), NOT in encoding (SMT-whole) nor coarse gluing (two blocks). The two subsets are the paradigm-degenerate *faces*; cooperation is the *interior*. = **FO(·)/IDP rebuilt on SMT-LIB-3.0's kernel**. SMT-LIB v3 (preliminary, smt-lib.org/version3.shtml) is *already* a CIC-inspired dependent-HO typed λ-calculus (kinds = HKT for free, `List:(→ Type Type)`; dependent sorts `BitVec n`; everything a term, formula=`Bool` term, quantifiers=HO fns; modules; `define-const-rec`+datatypes/recursors) "designed for HO-prover integration" → the user's HKT/HO requirements are SUBSUMED by adopting 3.0's kernel. Multiple concrete surfaces (SMT-LIB-v3 drop-in + Datalog face + new unified syntax) over ONE CIC kernel IR.
- **Semantics** = **stable-model/ASP from the foundation** (not well-founded-first). Reason: organic cooperation = *generate(ASP choice/stable) + constrain(SMT theory)*; well-founded-only = FO(·) define+constrain (missing the generative search half). Primitive solution = **ASPMT theory answer set** day-one; implementation stages (stratified/well-founded = deterministic special case), semantics is the full thing.
- **def/open**: `def` modifier → defined (closed-world, rule/inductive semantics), `open` modifier → open (classical/theory). Makes atom *ownership* explicit at compile time (theory atom = open-only; ASP atom = defined) → unambiguous trail/explain ownership.
- **Solver = one CDCL/MCSAT trail + propagators** (SMT theory + unfounded-set/stable + later CP) on shared trail. ASP guess = CDCL decision, theory check = DPLL(T), stable check = unfounded-set. Orchestrator layer (HO-ATP=Sledgehammer, IC3/PDR=Verilog, CEGAR/abduction, opt) calls the core as oracle — all "call core → learn → refine". Loose↔tight ASP-SMT coupling = a RUNG on oxiz-nl2's "freeze loop, grow explainer" ladder, NOT a one-shot bet (see gate below).
- **Three co-#1 use cases**: (a) verus backend, (b) Verilog formal utility (catch what testbenches miss — BV+arrays+CP word-level+BMC eDSL+IC3/PDR+CEX-trace; the GREENFIELD that exercises the full stack), (c) Isabelle Sledgehammer backend (HO + prover_emit-Isabelle reconstruction). Shared spine = uniform cert + typed IR. Killer arg: the superset PRESERVES recursion/defs/HO that plain SMT-LIB flattens into quantified axioms (= the verus MBQI/trigger-hell SOURCE) → strictly better IR for all three.

**Unified Verification Gate (the soundness spine)** — DESIGN DOC: `AD1/docs/design/UNIFIED_VERIFICATION_GATE.md` (committed AD1 `c5f8355`, main). Thesis: every verdict from any paradigm is trusted ONLY via an independent, cheap-where-possible, downgrade-on-fail gate over a paradigm-appropriate witness/cert → hybridization soundness ≈ 0 cost, and the loose/tight coupling is de-risked (soundness independent of coupling density → "when to tighten" only). Model side = *evaluate the witness* (uniform, cheap; ASP adds Horn-fixpoint stability, P for normal programs, composed AFTER G-SAT via the theory-relative reduct = ordered θ ⊳ M). No-model side = uniform in *shape* (verdict+checkable cert) but per-paradigm *kind* (DRAT / CAD covering / ASP loop-proof) — the SAME asymmetry oxiz-nl2 already has. Not-free items: disjunctive stability = co-NP; ordered θ⊳M composition (naive AND is wrong); ASP no-model cert unbuilt (but def/open-completion lets many "no answer set" ride existing DRAT/covering); grounder↔gate materialization contract.

**SCOPE = adsmt-WHOLE (user re-confirmed 2026-06-24):** hybridize is about adsmt *as a whole* (main SMT solver + verus backend + propagator bus + unified gate + 3 use cases), NOT the oxiz-nl2 leaf. Stack topology: **adsmt → (delegation) OxiZ (vendored, external/oxiz) → oxiz-nl2 (nonlinear leaf) → fdlcg (NIA CP prototype)**. `fdlcg` is the bottom-of-leaf *proving ground* for ONE bus slice; its real home is **adsmt's `TheoryHooks` propagator bus** (`external/oxiz/oxiz-sat/src/solver/theory_hooks.rs:45`). The fdlcg→bus mapping is clean (assign/unassign_hook=DomBox tighten/rollback, push/pop_frame=scoped box stack, final_check=propagate() cheap, final_check_complete=solve()+g_unsat_reverify, eval=interval sign); the ONE real re-architecture delta = **surrender fdlcg's private branch-and-prune to the shared CDCL trail** (a propagator only tightens+conflicts+reverifies; the trail branches). That delta IS "leaf vs adsmt-whole". = task #313 (S6).
