**#290 LANDED 2026-06-28 (OxiZ `53feaa3`→`3075a41` branch `0.2.4-redesign`; adsmt pointer `3552be7`; local/unpushed, no version bump).** `TermManager::substitute_cached` (`oxiz-core/.../manager/query.rs`) — the quantifier-instantiation substitution — was made TOTAL. A `Some(_) => id` catch-all had returned `Let`/`Match`/String/FP/BV/`Dt*` kinds UNCHANGED, so an instance body wrapping the bound var under one of those kept it (the **CCFV E/F leak**). Soundness rested on a fragile, UNASSERTED coupling: `OxizHost::view`-Opaque set ≡ this drop set (a dropped kind had to also be a non-descended `Opaque` leaf or `GroundIndex` would register a bare bound `Var` as ground).

**The fix:** the `Match` arm substitutes scrutinee + per-case-pattern-shadowed bodies; the capture-free structural kinds recurse via the complete `get_children` + rebuild via `transform_children` (made `pub(crate)`); `subst_under_bound_names` extracted from `subst_under_binder` (shared capture-avoiding bail: drop shadowed keys, BAIL leaving body unchanged on capture). **The `Let` arm INLINES (let-elimination)** `(let ((y v)) body)[σ] ≡ body[σ, y↦v[σ]]` — see the load-bearing fact below.

**THE LOAD-BEARING FACT (why Let inlines, not rebuilds):** OxiZ **inlines lets at PARSE time** — `parse_symbol` (smtlib/parser) resolves a let-bound name to its bound TERM, so a parser-built `Let{bindings, body}` has its body already inlined (no `y` refs) and `Let{b,body} ≡ body` always. BUT the theory layer **never REDUCES a `Let` node** — it treats it as an opaque value → a substituted-in `Let` is an undecidable instance → **spurious sat** (the "let-normalization gap"). So rebuilding a `Let` node during substitution would expose that gap; INLINING yields a let-FREE instance the engine decides. (`mk_let` has internal non-inlined callers — `rewrite/uf.rs`, `skolemization.rs` — so do the full inline via a combined subst `{σ\bound} ∪ {y↦v[σ]}`, NOT a blind wrapper-drop; sound + correct for both inlined and non-inlined Lets.) Result: instantiation now reaches AND decides through let bodies (`∀x.(= (f x)(let((y(+ x x)))(+ y x))) ∧ ¬(= (f c)(+(+ c c)c))` → `unsat`, was spurious `sat`).

**Verification (design→선검증→구현→differential→adversarial):** 선검증 `~/oxiz-total-subst-verification` (Verus **5/5**: `no_leak` — substituting `x` by a GROUND `r` removes every free `x` (the leak closed); `bail_keeps_subterm_free` — the capture bail is sound; minimal `Var`/`Node`/`Bind` model; no integer_ring). cvc5 differential (600 quantified-wrapper formulas: **0 soundness violations**, wrapper-body completeness **40/242→115/242** with inlining vs rebuild). 3-lens adversarial workflow — its let-in-quantifier spurious-sat findings ARE the cases the inlining fixed; the structural-rebuild (BV/string/FP/Dt) arms were verified faithful. +2 ground-soundness regressions; oxiz-core 1168 / oxiz-solver green.

**2 PRE-EXISTING soundness bugs the adversarial workflow surfaced (filed, out of #290 scope):**
- **#345** — top-level GROUND `let` term in arith is opaque → spurious sat (`(= (let ((w 99)) w) 50)` → `sat`). #290 fixed substitution-produced lets (inline); a let appearing directly in an assertion is not substituted, so it stays opaque. Fix = a let-elimination/normalization at assert/simplify time.
- **#346** — nested-quantifier capture-bail name-collision: an outer ∀ instantiated by a ground constant whose Spur name collides with an INNER binder's name makes `subst_under_bound_names` BAIL (sound — avoids capture) but leaves the outer var un-substituted → free-var instance → engine builds a spurious model (`ts_adv_19` → `sat`). Root: OxiZ shares one Spur for a declared constant and a same-named bound var. Predates #290 (Forall/Exists path). Fix = α-rename instead of bail, or drop the free-var instance.
