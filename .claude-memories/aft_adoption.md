The AFT review (`adopt-targeted`, see [[oxiz_nlsat_redesign]]) was IMPLEMENTED 2026-06-30 (user greenlit both adoptions + a new output-mode split). All LOCAL/UNPUSHED, no version bump.

**Core design (user steer):** the solver keeps the FULL verdict lattice internally — collapse to 3-valued {sat/unsat/unknown} happens ONLY at the final output boundary, and only in **z3-compatible mode** (the default = current OxiZ behaviour). **full mode** emits the un-collapsed verdict. Both CLI + in-process.

**SMT side — OxiZ submodule `0.2.4-redesign`, commit `c487576`:**
- `SatLevel` lattice completion (`oxiz-solver/src/solver/types.rs`): added `meet` (precision-meet — Unknown is identity; a confirmed pole dominates ANY unconfirmed guess; two opposing `Possibly*` ⇒ Unknown; never upgrades), `is_definite`, `as_full_str`. +6 unit tests.
- `Solver::check_level() -> SatLevel` is now the primary; `check()` = `check_level().collapse()`. Every early-return + engine verdict threads `SatLevel` to ONE collapse boundary (no premature 3-valued collapse). The two `verify_clean_*` adjudications now grade UNconfirmed outcomes as `Possibly*` (the previously-DEAD `PossiblyUnsat` pole is now constructed — symmetric unsat side). Soundness-neutral: collapse still maps every `Possibly*`/`Unknown` → sound `unknown`.
- `OutputMode {Z3Compatible default, Full}` on `Context` + `check_sat_level`/`last_level`/`set_output_mode`/`output_mode` accessors. `(check-sat)` renders collapsed or the 5-level token (`definite-sat`/`possibly-sat`/`unknown`/`possibly-unsat`/`definite-unsat`). CLI `--output-mode full`; SMT-LIB `(set-option :oxiz.output-mode full)`. The undecided-op `Sat` downgrade now → `PossiblySat` (was `Unknown`).
- Validation: 461 oxiz-solver lib tests + 6 lattice tests green; z3-compat QF_NIA differential FALSE_UNSAT=0/SPURIOUS_SAT=0 (verdicts byte-identical to pre-refactor — collapse path unchanged).

**ASP side — AD1 superproject, commit `4dd018e` (adsmt-ir-asp):**

New `ThreeValued {true_atoms=L*, false_atoms=B\U*, undefined_atoms=U*\L*}` + `Solution.well_founded: Option<ThreeValued>` populated on EVERY non-stratified program (polynomial, brackets every stable model — no longer discarded at the abstain sites).

In **Full** mode a stable-model enumeration OVER BUDGET no longer collapses to a total abstain (`Err`) — it returns the sound 3-valued WFM as a PARTIAL verdict (cautious-true `L*`, cautious-false `B\U*` — sound since `L*⊆every M`). The NEW capability the AFT review ranked #1. z3-compat keeps the historical abstain.

**P6 COMPLETE (2026-06-30, all three soundness bugs fixed sound+complete, each z3-differentialled):**
- **#351 LANDED (AD1 `e598d49`, native):** the hand-rolled bound+two-var FM pool can't represent a ≥2-var linear (in)equality/disequality (`x+y=z`, `x+y+z≤5`) or an LRA fractional bound (`2x=3`), so `assert` dropped it (`Ignored`) and `check` still returned a confident `Sat` — the soundness asymmetry ([[feedback_soundness_opaque_fallback]]). Fix: `LinArith.incomplete` flag (scoped push/pop), armed at every arith-drop point via `arith_atom_arity` (linearizes lhs−rhs; distinguishes a dropped ARITH constraint from a genuine other-theory literal like `(= (f x) 5)` → UF), `check` downgrades Sat→`Unknown` when a constraint was dropped → lu-smt's OxiZ delegation (z3-parity LIA) recovers the precise verdict; bare native stays sound at Unknown. polite combination: `Unknown` is now the WEAKEST verdict (remembered, not returned, so a UF-detectable Unsat still wins). 400-case multi-var QF_LIA differential 0 contradictions (267 agree, 133 sound downgrades); +4 tests.
- **#350 LANDED (OxiZ `1e518f5`):** the clean-MBQI DEFINITIONAL recognizer certified `∀x̄.f(x̄)=rhs` as `f:=λx̄.rhs` without accounting for ground terms that USE f's outputs — `∀x.f(x)=x ∧ ¬(g(f a)=g a)` read `sat` (defining f:=id forces g(f a)=g a). Root cause: `collect_ground_apps` treated ANY `Var` subterm as non-ground, but OxiZ models DECLARED CONSTANTS as `Var` too → `f(a)` over const `a` mis-classified non-ground → never recorded as a constraining f-point → f looked unconstrained (Pass 5 wrongly accepted). Fix: `collect_ground_apps_scoped` tracks the BOUND-var scope — a free Var (declared const) is GROUND, only a bound var OR a Skolem const (`sk!…`, kept symbolic) is non-ground. Completeness recovery: `ModelEval::eval_forall` now takes the live `cong` (generic `C:Congruence`, mirroring `model_completion`); a new branch fires the shortcut when every ground f-point is ALREADY `≃` its definitional value in E (`definitional_cong_consistent`, guarded `quant_count[f]==1`) — after instantiation the merge reflects in E (sound Some(true)); an inconsistent def conflicts at the ground core first. UF identity/definitional differential 150/150 agree (was 126 unknown sound-only); +2 tests.
- **#352 LANDED (OxiZ `acbfbd9`):** a bound var whose name collides with a declared constant — both `Var(name)`, hash-consed — became the SAME term, so a trigger `(f x)` was identical to a ground `(f x)` and the e-matcher read it as already-ground (no instantiation → spurious sat: `∀x.(p(f x))` pattern `(f x)`, `(f x)=x`, `¬(p x)`, const x). Fix: the SMT-LIB parser alpha-renames a bound var (`<name>!q<n>`) ONLY on collision with a declared const/outer binding (non-colliding names untouched → AOT bank/streaming/verus prelude unaffected); also fixes nested same-name shadowing. Collision differential 150/150 agree; +1 test.
