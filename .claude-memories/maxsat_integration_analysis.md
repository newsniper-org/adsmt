**출발점**: 사용자가 `.claude-research-libraries/`(PDF 6 + links.txt)를 읽고 MaxSAT를 external/oxiz+adsmt에 통합하는 방안·후속풀 연관·우선순위를 분석 요청(2026-07-20). 코퍼스: JAIR=MiniMaxSat(분기한정 weighted Max-SAT), nbjorner-nuz+scss2014=νZ(MaxRes core-guided + portfolio + Pareto/lex/box), 2411.12271=SMT-Layout(로컬서치 MaxSMT+GUI), LOPSTR-Slides=Max-SMT 프로그램분석(termination/invariant/weighted-abduction 패턴), CAV-2018 book=Typpete(MaxSMT Python 타입추론 — 응용 검증만, 신규 엔진기법 없음). links: Clarabel.rs(OMT-real conic 백엔드 후보), bitwuzla(BV-MaxSAT 참조).

**핵심 재구성 — OxiZ에 이미 있음**: `external/oxiz/oxiz-opt`(16,642 LoC, ~28모듈)이 RC2(rc2.rs 완전)·MaxRes(pmres.rs)·IHS/MaxHS·totalizer·cardinality·sortmax·SLS·LNS·Pareto·OMT·objective·wcnf·portfolio·preprocess + SMT-LIB command 표면(smtlib.rs/smtlib_commands.rs)을 구현. **3중 단절**: ① `optimization` optional feature(standard/full엔 있으나 default 아님), ② oxiz-cli/oxiz-solver 미의존(오직 oxiz-wasm만 end-to-end 도달), ③ pre-existing ignored 실패 3건(=이 프로젝트 5대 용인 실패 중 3건)을 안음.

**SAT-코어 계약은 이미 충족**: core-guided가 필요한 new_var/add_clause/`solve_with_assumptions→(result, core)`/model이 oxiz-sat에 전부 존재(solver/mod.rs:1091 + extract_assumption_core + AssumptionStack). **진짜 갭은 theory-레벨** — "SMT-under-assumptions가 theory-aware core 반환" API 부재 → theory MaxSMT가 core-guided 불가: `maxsmt.rs`는 스텁(Unknown 반환), 작동 경로는 `context.rs::optimize_maxsmt`가 전체 oxiz_solver::Solver를 합산-cost로 이진탐색(작동하나 core-guided 아님, **유리수 가중치가 1로 손실 강등**). `omt.rs`는 caller-checker 위 탐색루프(자체 theory 백엔드 없음).

**3개 red 테스트 근본원인(실행-진단, 전부 wrong-answer)**: (a) `pmres::test_pmres_all_satisfiable` — relax-var를 hard-clause var에서만 per-clause 시드 → 미방문 soft var(Var(1)) 에일리어싱 → phantom core → cost 1 vs 0(**fresh-id/pop-scrub 버그클래스**; relax var는 전 hard+soft 리터럴 max에서 시드해야). (b/c) `sortmax::*` — 정렬망 출력 방향/half-encoding 오류(outputs[0] 강제가 자명-sat에서 UNSAT). 둘 다 국소 수정 가능.

**adsmt 표면 = 전무**(maximize/assert-soft/get-objectives 0건). 훅: 위임 렌더 경로(adsmt-delegate/oxiz.rs proves_goal→render_smtlib→execute_script; 단 execute_script가 opt 명령 미파싱 + "trust unsat only" 방화벽 — OMT는 sat측 model+value 반환). **소인성 재framing**: 최적값의 하한 인증서 = unsat 증명("v보다 나은 feasible 없음")이라 기존 unsat 게이트로 신뢰 가능, witness는 sat-downgrade 규율. `OptLevel{Unbounded|Optimal(v)|BoundedBy(v)}`를 SatLevel/Confidence의 **분리곱 형제**(정밀도축⊥최적화축)로 추가. **잘못된 최적값 = soundness-class 버그** → z3/νZ-differential+코퍼스 게이트 규율 적용.

**킬러 앱(후속풀 연결) — ENABLED-BY MaxSAT**: ① **ASP weak-constraints**(`:~ [w@lvl]`) = stable model 위 MaxSAT, stratified-by-level=lexicographic MaxSMT — [[asp_post_l3_feature_decisions]]가 이미 oxiz-opt Weight+SoftClause에 겨냥(설계-확정, 코드 0). ② **weighted abduction/MPE**(−log p per abducible=min-cost hitting set) = weighted-partial-MaxSAT, LOPSTR "hard=건전성/soft=최대 discharge" 패턴, "DEFINITELY implement"; 현 `adsmt-abduce/rank.rs`(score=|hyps|+0.001·depth 브루트-열거후정렬)를 core-guided 최적성으로 대체. ③ 최적 abductive 랭킹/L3 CostFunction(②에 흡수). **ENABLER**: fgr simplex warm-start(후속풀 rank-4) — OMT-over-LRA는 목적-바운드 위 반복 증분 simplex, warm-start가 정확한 가속(νZ unbounded 경로). 나머지 후속풀(work-bounded emission/EUF find-caching/V1 replay/#426/#427/Dt-as-App)은 전부 직교·무관(blocked-by 없음). multi_paradigm_hybridization가 "opt"를 1급 오케스트레이터 패러다임으로 이미 명명(core→learn→refine=core-guided MaxSMT CEGAR).

**우선순위 권고**: **근시일 병렬 트랙**(verus-facing perf 앞지르지 않음 — perf 아무것도 안 막고 fgr-warm-start 1건만 접점). 그러나 지금 할 근거 강함: 16k-LoC 미사용 자산 + 3 red 테스트가 oxiz-opt 승격 순간 shipping-blocking화 + 설계-확정 2기능의 유일 백엔드. **단계**: P0=pmres 시드+sortmax 방향 수정 + fix-then-flip default 결정(버그픽스 검증) → P1=oxiz-cli (maximize)/(assert-soft) end-to-end + z3/νZ differential(soundness-class) → P2=adsmt SMT-LIB opt 표면 + ASP-weak 백엔드(clingo/clasp+z3 OMT differential) → P3=weighted abduction. **최소 고가치 첫걸음=P0**(2개 국소 wrong-answer 수정 + default 결정 → 자산화). **거버넌스**: opt 작업은 pending §4 upstream MR 밖 신규 vendored 발산 — upstream-MR-레이어 vs vendor-only 결정 필요.

**실행 착수 (2026-07-20)**: 사용자 지시로 `0.2.4-redesign`에서 `0.2.4-fill-the-gap/maxsat` 브랜치 fork, P0→P1(oxiz)→merge→P2→P3(AD1 main)→verus-perf 재개 순서로 계획 승인.

**P0 LANDED (oxiz `ce47dbe`)**: pmres.rs(relax-var upfront 시딩) + pmres_enhanced.rs(독립 중복구현, 동일 패턴 재적용) + sortmax.rs(정렬망 출력방향 반전 + 별도 aliasing 버그) + cardinality_network.rs(잠복 쌍둥이 버그+신규 정확성 테스트) 수정. **differential 검증 중 4건 추가 잠복 버그 발견·수정**(pmres의 core-constraint 방향 반전 오류, empty-assumptions stale-cost 폴스루, sortmax의 soft-only aliasing). **핵심 발견: rc2.rs 자체가 unsound**(진짜 최적값 7인데 stratified 경로가 3 보고, non-stratified도 9로 안 tight) — differential 오라클을 rc2 대신 brute-force(≤12 var 전수)로 교체. `rc2_enhanced.rs`는 rc2.rs 미참조 독립 구현(pmres/pmres_enhanced와 동일한 비-공유 패턴)이라 이 버그를 기계적으로 상속하진 않으나 **미검증** — **P2 설계가 이 코드의 stratification을 명시 인용했으므로, 자체 differential 없이 진행 금지**(같은 버그클래스가 형제 파일에서 2회 독립 재발한 직후라 신뢰 불가). 게이트: oxiz-opt 0 ignored(기존 3→0), 워크스페이스 5→**2** 용인 ignored 실패로 축소(nl2 differential_full, spacer test_counter_unsafe만 잔존). 적대 2렌즈 GREEN, P0/P1 발견 0.

**P1 LANDED (oxiz `4ada5ce`, merge `01d0328`, AD1 범프 `d7dc647`)**: `(maximize)/(minimize)/(assert-soft)/(get-objectives)` end-to-end 배선. 핵심 걸림돌(OptContext가 자체 TermManager 소유) 해법 — 신규 `transplant_term`(oxiz-core, 반복형·메모이즈, 빌트인 소트만) + 신규 `oxiz-opt/src/script.rs::OptScriptRunner`. **계획에 없던 아키텍처 발견**: oxiz-solver→oxiz-opt 의존 추가는 **순환 패키지 의존**(oxiz-opt가 이미 oxiz-solver에 의존)이라 Cargo가 거부 — `execute_script`를 `execute_one`/`execute_one_known`으로 분리해 우회. **z3 differential 1차 89.1%에서 근본원인 추적 결과 결정적 발견: MaxSAT 배선과 무관한 base `oxiz_solver::Solver` 자체가 QF_LIA에서 false-UNSAT**(6개 이상 selector/cost 그룹 합산 시 — 5개는 정상, 6개부터 오작동; z3+cvc5 둘 다 sat 확인) — **신규 이슈 #428**(repro 2건 corpus-triage 보존, 메인 세션이 직접 최소축소 재현·검증). 순수-Boolean MaxSAT은 신규 `bool_cnf_maxsat.rs`(Tseitin CNF + totalizer 이진탐색, Int 비용변수 자체를 안 만들어 #428 회피)로 우회했으나 **LIA-혼합 폴백 경로는 #428에 계속 노출**. **P0의 "PmresSolver=fixed+differential-tested" 평가에 대한 정정**: 실제로는 mixed-weight multi-literal 코어에서 weight-blind(cost 20 vs 진짜 5) — 다른 셰이프였을 뿐 P0 differential이 놓친 사각지대. fixup이 8건(get-objectives stale값, Pareto ∞ 오보고, 유리수 weight 절삭, opt_error pop 미해제 등) 추가 발견·수정 후 **z3 최적값-정확성 differential 300/300=100%**(게이트 대상 카테고리; omt_compound·maxsat_grouped는 사전-존재/미결정 사안으로 명시 제외, 은폐 아님). 적대 2렌즈 모두 1차에서 실전 P0/P1 발견(도합 8건) → 재검증 GREEN.

**P3 LANDED (AD1 `5d337f8`) — MaxSAT P0-P3 이니셔티브 완결**: weighted abduction/MPE, `(declare-abducible ... :weight w)`(기본 1.0, 완전 하위호환). **두 설계 결정 모두 P2 선례를 그대로 승계**: 탐색범위=이미 열거·최소화된 후보 재랭킹(argmin), 위임경계=live MaxSAT 재탐색 없음(P2 `adsmt-delegate/src/asp.rs`의 근거를 명시 인용) — 신규 Cargo 의존성 0, external/oxiz 무변화. `rank_candidates`+`abduct_goal_relevance` 두 중복 경로를 `candidate_cost=Σweight+0.001·depth`로 통합. 게이트: brute-force 최적-랭킹 differential 150+독립 500(합 600, 0 패배), mutation-test로 게이트 비-공허 확증, f64가 P2의 i64-wrap 버그클래스를 자연 회피(overflow시 +inf saturate)함을 명시 검증. 적대 렌즈 P1 적발(malformed weight 조용한 1.0 기본값 대체 — 수정, hard-error화). 실측 e2e 스팟검증: weight 1 vs 5 두 독립 경로에서 정확히 싼 쪽이 1위(score 1.003 vs 5.003).
