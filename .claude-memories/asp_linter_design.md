**The unsoundness/vacuity LINTER** — user-proposed 2026-06-26 ("사용자나 ITP가 adsmt에 입력시킨 코드 안에 unsound한 논증들이 있는지 미리 잡아내는 linter"). Analyzed via a 13-agent workflow (4 design lenses → synthesize → adversarial-verify). **It is the exact DUAL of the abductive surface** ([[abductive-smtlib-surface]]): abduce finds hypotheses that MAKE a goal entailed; the linter finds when the EXISTING hypotheses are self-defeating (vacuous). The dominant real ITP unsoundness is not the solver being wrong but the user's **assumptions being self-contradictory** so `H ⊢ G` passes vacuously (false precondition / contradictory invariant / `requires false`).

**ARCHITECTURE (4 lenses converged):** a pure **OBSERVER behind the soundness firewall** — reads only already-trusted outputs (FhVerdict / `Solution::consistent` / `least_model` / `pred_strata` / `Stratification` / the SExpr+converted Term) and emits side-channel diagnostics; **NO write path to the verdict** (3 structural layers: TIMING — solve-based hooks run INSIDE CheckSat strictly AFTER `record_result`, return `DispatchResult` unchanged; static hooks run at parse/assert/elaborate, the constraint set the solver sees is byte-identical lints-on-or-off so the SOUNDNESS ASYMMETRY is never triggered; ISOLATION — every probe is a separate push/check-sat/pop bracket or a read-only projection; CHANNEL — stderr/JSON/`(get-lints)`, never the verdict stream). A linter bug yields ONLY a missing/spurious Info/Warning line, never a flipped/manufactured verdict. **THE HARD-WARNING RULE:** a hard "vacuous/inconsistent-context" fires only on a DEFINITE unsat proof of the context (`FhVerdict::Unsat` for SAT(H), or ASP `consistent==false`/least_model⊢⊥); a solver Unknown on H is SILENCE → at most a soft note. **LINT-ATTR rule:** every hard warning is phrased "the solver found H unsatisfiable on its own (backend=…)", never "your context is contradictory" — so even a buggy solver yields a misleading note, never a trusted wrong claim.

**CATALOG (12 rules; MVP = the keystone + cheap static, all zero-to-low FP):** `LINT-VAC` (vacuous context, both faces, the keystone — SMT: `decide_fh(&[], goal-stripped history)`, the empty-hypothesis case of `abduct_is_consistent` ~30 LoC; ASP: `Solution::consistent==false`/no answer set) + `LINT-TRIG-MISSING` (static, Info — no `:pattern`/Miller/coverage via `Trigger::is_miller`+`learn_triggers`, reads the SExpr layer since `convert_annotation` drops `:pattern`) + `LINT-ASP-UNSAFE` (static — mirror elab.rs safety `in_body||in_pattern` verbatim; pre-flights the existing `FaceError::Unsafe`) + `LINT-ASP-NONSTRAT` (static — `compute_strata`/`Stratification::NonStratified`, additive to the gate) + `LINT-ATTR` (phrasing/emission discipline). **Non-MVP:** `LINT-VAC-SOFT` (Unknown→soft note), `LINT-AXIOM` (`assert false` + provenance-marked axioms), `LINT-OVERCON` (ground term pinned to 2 values), `LINT-MATCHLOOP` (high-FP, gated on an empirical sweep over the verus prelude + OxiZ 168-corpus), `LINT-UNFUELED-REC`, `LINT-ASP-DEADABD`, `LINT-ASP-DEADRULE`.

**SURFACE = DEFAULT OFF** (`--lint`/`(set-option :lint true)` next to `:abduct-consistency`; per-rule sub-gates; LINT-VAC carries a SEPARATE small budget NOT shared with `:rlimit` + caches SAT(H) on the clause-set digest; side channel = stderr WARNING lines / versioned `{"lints":[…]}` JSON reusing `adsmt-lints DiagnosticsDocument` / a read-only `(get-lints)` command on the no-exit recoverable path). **Placement:** extend the existing `adsmt-lints` crate (its lib.rs already reserves a "Future lu-kb-side audits" slot) for SMT/ITP; a sibling `adsmt-ir-asp/src/lint.rs` for ASP; a shared extracted Severity+DiagnosticsDocument so one LSP squiggle path consumes both. **Two verus-fork coordination asks precede Phase 1:** (a) a `(! ¬G :goal-negation)` goal-frame tag for LINT-VAC's H-isolation (the negated goal is today a plain unmarked `(assert …)`); (b) a `:named`/`:qid` axiom-prefix convention for LINT-AXIOM.

**ADVERSARIAL VERIFY found 3 corrections — all "major", NONE a blocker (the firewall holds: every one is an advisory-quality FP, no verdict flip, confirmed by RUNNING repros against real lu-smt):** (1) **LINT-VAC HARD-FP on intentional vacuity** — unreachable arms (`x>0∧x<0`), dead loop bodies (`n≤0∧0≤i<n`), `requires false`/`assume false` lemmas all have a DEFINITE-unsat H by design → the hard "vacuous-context" warning fires on SOUND code; the spec's "a genuine FP requires a solver bug" is empirically FALSE (the solver is correct that H is unsat — the FP is the semantic premise `unsat(H) ⟹ defect`). ALSO the cost model is INVERTED: a discharged VC is `F∧¬G` unsat, so Unsat is the COMMON path → LINT-VAC ~doubles per-VC solve cost. (2) **LINT-AXIOM HARD-FP on `(assert false)`** — the legitimate discharge-by-contradiction idiom flagged as "unjustified axiom"; also `:named` is dropped by `convert_annotation` so provenance MUST read the raw SExpr. (3) **LINT-OVERCON FP on literal aliasing** — `(f 0)=10` vs `=010` (same value, distinct text) flagged "vacuously unsat" on a SAT input (numeric literals are verbatim text at the Term layer; meaning lives in the simplex). Common fix: **hard→Info/soft + neutral wording + separate budget**.
